This is a fun little RNG game I am working on and hopefully will add more features to I am submitting it to crescent as I continue to build upon it.

The gameplay loop is simple, you open chests and get items using those items eventually you will be able to craft things which will upgrade things such as chest spawn rate or chest open rate. You can also eventually get these from chests. Eventually there will be an upgrade shop where you sell materials to upgrade chest spawn rate and amount of chests, as well as chest spawn percentage. (So rare items have a higher chance to spawn) I hope to continue working on this game and making it better!
